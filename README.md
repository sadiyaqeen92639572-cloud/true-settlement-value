# True Settlement Value

Free, no-signup personal injury settlement calculators using the multiplier method,
state-aware comparative/contributory negligence rules, and researched noneconomic
damage caps. Also includes a separate statutory-cap calculator for EEOC / employment
discrimination claims (Title VII, ADA, ADEA, California FEHA).

Live site: [truesettlementvalue.com](https://truesettlementvalue.com)

Not a law firm. Educational estimates only, not legal advice.
